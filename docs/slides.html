What you are about to see

  1. It opens with something it already saw. Bonsai-2 9B took one look while the call rang.
  2. I repeat the word, then two phrases. Each character is coloured by WhisperKit's word confidence.
  3. We just talk. Bonsai-2 9B, text only: it looks at a frame only when I ask.
  4. "What is this?" One 512 x 288 frame; the first sentence is spoken while the rest is written.
  5. Goodbye. The receipt: what it saw, what it kept, what left the Mac.

How it uses Bonsai and Argmax

Code decides which model answers. Never a model.

Tier 0
No model
Commands, yes and no, scoring a repeated word, swapping learned words into sentences. Half of the responses in a call.
Tier 1 · GPU
Bonsai-2, text only
Conversation on the 9B with 30 seconds of talk and a compressed memory. Two short lines on the 4B.
Tier 2 · GPU
Bonsai-2 9B + one frame
Only when you talk about the picture, or the conversation has run dry. 1 look in 560 frames.
Neural Engine
Argmax WhisperKit
Whisper large-v3 and Whisper small, both loaded: the small one answers first, the large one when unsure. Word probabilities drive the colours; the word being practised is passed as a prompt.
Neural Engine
Argmax TTSKit
One voice across two languages, native in the one you learn. Sound starts at the first chunk; the next sentence is made while this one plays; every sentence is cached.

Why local

It remembers your words,
not your face.

A tutor that watches you through a camera is only acceptable if nothing leaves the room. So the frames and the audio live in memory only, the page proves that no connection leaves the Mac, and after the call the only thing kept is the list of words you learned.

Right-sized on purpose: rules before models, the small model before the large one, one frame instead of video, cached speech instead of new speech.

Next: the same call through a pocket device (a Raspberry Pi as camera, microphone and speaker over Bluetooth), so it can travel.
